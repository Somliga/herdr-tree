# Timeline model (v2) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the tree a timeline you can rewind, summarise a range of, and fold a branch's knowledge back into at a point you choose.

**Architecture:** Three features that are all one primitive — rewind plus seed. Branching already writes a new transcript containing the ancestor chain of a chosen turn; seeding appends one entry to it before resuming. Summarising grafts at a range's end, resumes with a prompt naming the start, captures stdout and deletes the temporary session. Folding back at the live parent's end skips grafting entirely and sends the summary with `herdr agent prompt`.

**Tech Stack:** Go 1.27, Bubble Tea, Lipgloss for colour. Stdlib elsewhere.

**Spec:** `docs/superpowers/specs/2026-09-22-timeline-design.md`

## Global Constraints

- The v1 spec (`docs/superpowers/specs/2026-09-21-herdr-tree-design.md`) stands. Everything it forbids stays forbidden.
- Never modify a source transcript. Every operation writes a NEW session or sends a message; nothing on disk is edited or deleted.
- Never delete a session the user could still resume, including orphans from a failed operation.
- Grafted transcripts are mode `0600`, written tmp-then-rename.
- `internal/tui`, `internal/tree` and `internal/store` must not import `internal/claude`.
- Never log message content. Ids, counts, paths and byte sizes only.
- `renderRow` returns UNSTYLED text plus a style key. `View` applies colour. A large number of tests assert on exact row content.
- Colour reinforces; every distinction it carries is also a glyph or prefix.
- Every API call is user-initiated and its cost stated before it happens.
- Verified against Claude Code 2.1.278 and Herdr 0.9.1 only.

// Summary is an LLM summary of a RANGE of turns. It belongs to a span, not a
// session: the same session can be summarised over different spans, and
// folding one back has to name which.
type Summary struct {
	Text      string    `json:"text"`
	SessionID string    `json:"session_id"`
	FromTurn  string    `json:"from_turn"`
	ToTurn    string    `json:"to_turn"`
	CreatedAt time.Time `json:"created_at"`
}

// SummaryKey identifies a span.
func SummaryKey(sessionID, fromTurn, toTurn string) string {
	return sessionID + ":" + fromTurn + ".." + toTurn
}

// AddSummary records or replaces the summary for a span.
func (s *Store) AddSummary(sum Summary) {
	if s.Summaries == nil {
		s.Summaries = map[string]Summary{}
	}
	s.Summaries[SummaryKey(sum.SessionID, sum.FromTurn, sum.ToTurn)] = sum
}

// SummariesFor returns every summary recorded against a session, oldest first.
func (s *Store) SummariesFor(sessionID string) []Summary {
	var out []Summary
	for _, v := range s.Summaries {
		if v.SessionID == sessionID {
			out = append(out, v)
		}
	}
	sort.Slice(out, func(i, j int) bool { return out[i].CreatedAt.Before(out[j].CreatedAt) })
	return out
}
```

package tree

// Trunk returns the set of session ids on the current lineage: the session you
// are in, and every session it was grafted from, back to a root.
//
// Nothing about the trunk is stored or marked. It is computed at render time
// from wherever you happen to be, so rewinding — which puts you in the new
// session — moves the trunk for free. An explicit pointer would need
// maintaining and could disagree with where you actually are.
//
// An empty current session yields an empty set, and the caller falls back to
// presenting every session as a root.
func Trunk(roots []*Node, currentSession string) map[string]bool {
	on := map[string]bool{}
	if currentSession == "" {
		return on
	}
	parentOf := map[string]string{}
	var walk func(n *Node)
	seen := map[*Node]bool{}
	walk = func(n *Node) {
		if seen[n] {
			return
		}
		seen[n] = true
		for _, c := range n.Children {
			if c.SessionID != n.SessionID {
				parentOf[c.SessionID] = n.SessionID
			}
			walk(c)
		}
	}
	for _, r := range roots {
		walk(r)
	}
	for sid := currentSession; sid != ""; sid = parentOf[sid] {
		if on[sid] {
			break // a cycle in a hand-edited store must not hang this
		}
		on[sid] = true
	}
	return on
}
```

### Task 2b: Render the trunk as the main line

**Files:**

Task 2 computes which sessions are on the trunk. Without this task nothing
consumes it: `styleFor` in Task 7 takes an `onTrunk` flag that no caller would
ever set, and spec §3's presentation — trunk at depth 0, branches indented at
the turn they diverged from — would not happen.

The trunk is the line you are on. If your current session was grafted from
another, the v1 build renders it *indented under its parent*, which is exactly
backwards: the line you are working on should be the main line, and the one you
left should be the branch.

// summariseTimeout bounds the model call. Summarising a long range is slow,

const summariseTimeout = 5 * time.Minute

// SummarisePrompt asks for the four things that make a summary worth folding
// back. "Rejected, and why" matters most: it is what stops the trunk paying
// again for a dead end this branch already explored.
func SummarisePrompt(fromTitle, toTitle string) string {
	return fmt.Sprintf(`Summarise only the part of this conversation from the turn beginning %q up to and including the turn beginning %q. Ignore everything before that range except as context.

Write four short sections:
- Attempted: what this stretch was trying to do.
- Decided: what was settled, and the reasoning.
- Rejected: what was tried and abandoned, and why not. Be specific; this is what stops the work being repeated.
- Unfinished: what remains.

Be concise and concrete. Do not use any tools. Reply with the summary only.`,
		fromTitle, toTitle)
}

// Summarise produces a summary of the turns between fromTurn and toTurn.
//
// It grafts the source at toTurn into a throwaway session, resumes that with
// the prompt, captures stdout and removes the throwaway. The graft is needed
// because --resume always continues at a session's tip: summarising "up to
// turn 12" must not let the model see turn 13.
func Summarise(srcPath, fromTurn, toTurn, tmpCWD string) (string, error) {
	es, skipped, err := ParseFile(srcPath)
	if err != nil {
		return "", err
	}
	if skipped > 0 {
		return "", ErrPartialTranscript
	}
	title := func(id string) string {
		for _, e := range es {
			if e.UUID() == id {
				return Title(e.Text(), 60)
			}
		}
		return id
	}

	sid, path, err := Graft(srcPath, toTurn, tmpCWD)
	if err != nil {
		return "", err
	}
	// The one place this project removes a session: we made it moments ago
	// for this call alone, and nothing else can have learned of it.
	defer os.Remove(path)

	ctx, cancel := context.WithTimeout(context.Background(), summariseTimeout)
	defer cancel()
	cmd := exec.CommandContext(ctx, "claude", "-p", "--resume", sid,
		SummarisePrompt(title(fromTurn), title(toTurn)))
	cmd.Dir = tmpCWD
	cmd.Stdin = nil
	out, err := cmd.Output()
	if ctx.Err() == context.DeadlineExceeded {
		return "", fmt.Errorf("summarise timed out after %s", summariseTimeout)
	}
	if err != nil {
		var ee *exec.ExitError
		if ok := asExit(err, &ee); ok {
			return "", fmt.Errorf("claude: %s", strings.TrimSpace(string(ee.Stderr)))
		}
		return "", err
	}
	text := strings.TrimSpace(string(out))
	if text == "" {
		return "", fmt.Errorf("claude returned an empty summary")
	}
	return text, nil
}

func classifyAgentError(b []byte) error {

		Error *struct {
			Code    string `json:"code"`
			Message string `json:"message"`
		} `json:"error"`

		return nil

		return ErrAgentBlocked

	return fmt.Errorf("herdr: %s: %s", r.Error.Code, r.Error.Message)

func (m *Model) BeginRange() {

func (m *Model) RangeSpan() (from, to *tree.Node, ok bool) {

Three user-visible operations, one primitive underneath:

- **`s`** fixes a range end, you move to the start, confirm. The summary is
  generated and stored. Nothing else happens.
- **`p`** (paste-back) on a turn offers the summaries available and appends the
  chosen one here. At the live parent's end that is `AgentPrompt`; anywhere
  else it is `BranchSeeded`.
- **Compaction** is `p` with a summary of this same line: the machinery does
  not distinguish it, only the classifier and the colour do.

```go
// claudeSummaryPrefix mirrors claude.SummaryPrefix. internal/tui must not
// import internal/claude, so the marker is duplicated deliberately; a test in
// cmd/herdr-tree asserts the two agree.
const claudeSummaryPrefix = "⤶ summary of"

func summariseCmd(a adapter.Adapter, st *store.Store, from, to *tree.Node) tea.Cmd {
	return func() tea.Msg {
		src := adapter.Session{ID: from.SessionID, CWD: from.SessionCWD, Path: from.SessionPath}
		text, err := a.Summarise(src, from.Node.ID, to.Node.ID)
		if err != nil {
			return actionDoneMsg{status: "summarise failed: " + err.Error()}
		}
		st.AddSummary(store.Summary{
			Text: text, SessionID: from.SessionID,
			FromTurn: from.Node.ID, ToTurn: to.Node.ID,
			CreatedAt: time.Now().UTC(),
		})
		if err := st.Save(); err != nil {
			return actionDoneMsg{status: "summarised, but not saved: " + err.Error()}
		}
		return actionDoneMsg{status: "summarised " + shortID(from.SessionID)}
	}
}

func foldBackCmd(a adapter.Adapter, st *store.Store, at *tree.Node, dst string, sum store.Summary, liveAgent string) tea.Cmd {
	return func() tea.Msg {
		seed := claudeSummaryPrefix + " " + shortID(sum.SessionID) + "\n\n" + sum.Text
		if at.IsSessionLeaf && liveAgent != "" {
			if err := herdr.AgentPrompt(liveAgent, seed); err != nil {
				return actionDoneMsg{status: "could not send to the agent: " + err.Error()}
			}
			return actionDoneMsg{status: "sent to " + liveAgent, quit: true}
		}
		src := adapter.Session{ID: at.SessionID, CWD: at.SessionCWD, Path: at.SessionPath}
		sid, err := a.BranchSeeded(src, at.Node.ID, dst, seed)
		if err != nil {
			return actionDoneMsg{status: "fold back failed: " + err.Error()}
		}
		st.Add(sid, store.Branch{
			GraftedFrom: store.From{SessionID: at.SessionID, Node: at.Node.ID},
			Title:       "⤶ " + Title(sum.Text, 40),
			CreatedAt:   time.Now().UTC(),
		})
		if err := st.Save(); err != nil {
			return actionDoneMsg{status: "folded " + shortID(sid) + ", but the tree was not saved: " + err.Error()}
		}
		if err := a.Resume(sid, dst); err != nil {
			return actionDoneMsg{status: "folded " + shortID(sid) + ", but it did not open: " + err.Error()}
		}
		return actionDoneMsg{status: "folded into " + shortID(sid), quit: true}
	}
}
```

Key handling: `s` calls `BeginRange` then, on the next `s` or `enter`, confirms
and dispatches `summariseCmd` — showing the range's size first, as the v1
confirm dialog does for a branch. `p` opens a picker listing
`st.SummariesFor(...)` across all sessions, and on choice dispatches
`foldBackCmd`. `esc` cancels either.

Where the chosen branch has no summary, the picker offers "summarise it first"
rather than refusing — the spec's offer-never-force rule.

Footer becomes:

```
↑↓ move  ←→ fold  ⏎ continue  s summarise  p fold back  L label  a scope  f filter  esc close
```

cleanup() {

## Notes for the implementer

**The riskiest code is Task 5.** Summarising deletes a session file — the only
place this project does. It is safe only because the file was created moments
earlier by the same function for this call alone. If you find yourself deleting
anything you did not just create, stop.

**Task 6's blocked-agent path must not fall back.** If the agent will not take
input, say so. Silently grafting instead gives the user a fork they did not ask
for, and they will not notice until the tree has two lines where they expected
one.

**Do not let `internal/tui` import `internal/claude`.** The summary prefix is
deliberately duplicated rather than imported; the constant is three words and
the boundary is worth more.

**The colour palette is one table.** If you find yourself writing a colour
anywhere else, put it in the table instead.
